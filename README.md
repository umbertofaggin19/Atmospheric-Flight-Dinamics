# Atmospheric-Flight-Dinamics 
script9.m = 3 DoF simulator for 3d flight (Euler Angles)
script12.m = 6 DoF simulator for 3d flight with controls (Euler Angles)
trimm.m = function to calculate parameters (thrust, ailerons/finn deflection, phi,...) to get flight with zero translational and rotational accelerations

To view the simulation, download "scriptX.m", then open Matlab (R2020a or later) and type "scriptX" on the Command Window to run the simulation
